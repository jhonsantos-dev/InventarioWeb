InventarioWeb

Proyecto CRUD desarrollado en ASP.NET Web Forms con SQL Server.

Funcionalidades:

Crear productos
Editar productos
Eliminar productos
Listar productos

Tecnologías usadas:

C#
ASP.NET Web Forms
SQL Server
Stored Procedures

Cómo ejecutar el proyecto:

1.Clonar el repositorio
2.Abrir en Visual Studio 2019
3.Configurar la cadena de conexión en Web.config
4.Ejecutar la base de datos con los script SQL en el orden que estan(1,2,3)
5.Ejecutar el proyecto

Base de datos

El script de la base de datos se encuentra en la carpeta:

/Database/1.sql
/Database/2.sql
/Database/3.sql
